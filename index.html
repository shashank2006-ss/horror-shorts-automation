Horror Shorts Automation

Horror Shorts Automation is a personal automation project designed to create and publish original Hindi horror and suspense stories as YouTube Shorts.

What the application does

  • Generates original story content using Google Gemini.
  • Finds stock video footage using Pixabay.
  • Generates Hindi narration using text-to-speech.
  • Combines narration and footage into short videos.
  • Uploads videos to the owner's YouTube channel using the YouTube Data API.
